# 세장섯다 온라인 (3장 섯다)

화투로 하는 한국 민속놀이 **섯다**를 친구들과 온라인으로 즐기는 게임입니다.
세 장을 받아 그중 두 장으로 족보를 만드는 **세장섯다** 방식이며, 한 방에 **최대 5명**까지 들어갈 수 있습니다.

- 방을 만들면 4자리 **방 코드 / 초대 링크**가 생기고, 친구가 들어오면 바로 시작
- 빈자리는 **컴퓨터**로 채울 수 있음
- 패는 **서버에서만** 섞고 나눠줌 → 다른 사람 패는 개발자 도구로도 볼 수 없음
- 차례 제한 시간(15/30/60초), 시간 초과 시 자동 체크(못 하면 다이)
- 새로고침·연결 끊김 시 **자동 재접속**, 게임 중 난입은 다음 판부터 참여
- 채팅, 진행 기록, PC·모바일 화면 대응
- 혼자 컴퓨터랑 연습하는 오프라인 모드(`local.html`)도 포함

## 실행하기 (내 컴퓨터)

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 같은 와이파이의 친구는 `http://<내 컴퓨터 IP>:3000` 으로 들어올 수 있습니다.

## 인터넷에 올리기 (GitHub + Render 무료)

GitHub는 코드를 보관하는 곳이고, 게임 서버는 Node를 실행해 주는 호스팅이 필요합니다. 여기서는 Render 무료 플랜 기준으로 설명합니다.

1. 이 폴더 전체를 GitHub 저장소에 올립니다 (`node_modules`는 올리지 않아도 됩니다).
   ```bash
   git init
   git add .
   git commit -m "세장섯다 온라인"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소이름>.git
   git push -u origin main
   ```
2. [render.com](https://render.com)에 GitHub 계정으로 가입합니다.
3. **New → Web Service** 에서 방금 올린 저장소를 고르고 아래처럼 설정합니다. (저장소에 들어 있는 `render.yaml`로 **Blueprint** 배포를 해도 같은 설정이 적용됩니다.)
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. 배포가 끝나면 나오는 `https://<이름>.onrender.com` 주소를 친구들에게 공유하면 됩니다.

이후에는 GitHub에 push할 때마다 Render가 자동으로 다시 배포합니다.

### 무료 플랜 주의사항

- 15분 동안 아무 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 1분 정도 걸립니다. 첫 사람이 접속해서 잠깐 기다리면 됩니다.
- 방 정보는 서버 메모리에만 있어서, 서버가 재시작·재배포되면 진행 중인 방이 사라집니다.
- 항상 켜 두고 싶으면 유료 플랜을 쓰거나 다른 Node 호스팅(Fly.io, Railway, 개인 서버 등)에 올려도 됩니다. `PORT` 환경변수만 지원하면 어디서든 돌아갑니다.

### 화면만 GitHub Pages에 따로 올리고 싶다면 (선택)

`public/js/config.js`의 `window.SEOTDA_SERVER`에 서버 주소(`wss://<이름>.onrender.com/ws`)를 적고 `public` 폴더를 Pages로 배포하면 됩니다. 서버 쪽에는 `ALLOWED_ORIGINS=https://<아이디>.github.io` 환경변수를 넣어 다른 사이트의 접속을 막을 수 있습니다. 서버째 올리면 이 과정은 필요 없습니다.

## 게임 규칙

### 진행

1. 모두 **학교비**(기본 판돈)를 냅니다.
2. 두 장씩 받고 **1차 베팅**.
3. 세 번째 장을 받은 뒤, 세 장 중 **한 장을 버려** 두 장으로 족보를 정합니다.
4. **2차 베팅** 후 남은 사람끼리 패를 공개, 높은 족보가 판돈을 가져갑니다.
5. 이긴 사람이 다음 판의 **선**. 칩이 0이 되면 탈락, 사람이 모두 탈락하거나 1명만 남으면 게임 종료.

### 베팅

| 액션 | 설명 |
|---|---|
| 체크 | 아무도 걸지 않았을 때 넘김 |
| 삥 | 첫 베팅을 학교비만큼 |
| 콜 | 앞사람 베팅만큼 맞춤 |
| 따당 | 앞사람 베팅의 두 배로 올림 |
| 하프 | 콜한 뒤 판돈의 절반만큼 더 올림 |
| 다이 | 포기 (낸 돈은 판에 남음) |

한 라운드에 1인당 레이즈는 2번까지. 칩이 모자라면 올인하고, 넘치는 금액은 사이드팟으로 나뉩니다.

### 족보 (높은 순)

38광땡 > **18광땡 > 13광땡** > 장땡 > 9땡 … 삥땡 > 알리(1·2) > 독사(1·4) > 구삥(1·9) > 장삥(1·10) > 장사(4·10) > 세륙(4·6) > 갑오(9끗) … 1끗 > 망통(0끗)

### 특수패

| 패 | 구성 | 효과 |
|---|---|---|
| 땡잡이 | 3월광 + 7월열끗 | 상대 최고패가 1~9땡이면 승리, 아니면 망통 |
| 암행어사 | 4월열끗 + 7월열끗 | 상대 최고패가 13·18광땡이면 승리, 아니면 1끗 |
| 구사 | 4월 + 9월 | 최고패가 알리 이하면 재경기, 아니면 3끗 |
| 멍텅구리구사 | 4월열끗 + 9월열끗 | 최고패가 9땡 이하면 재경기, 아니면 3끗 |

같은 족보끼리는 판돈을 나눠 가집니다.

## 파일 구조

```
server/server.js     HTTP(화면 파일) + WebSocket 서버, 방 목록
server/room.js       방 하나: 대기실, 게임 진행, 차례 타이머, 개인별 화면 데이터
public/index.html    온라인 화면 (입장 · 대기실 · 테이블)
public/local.html    오프라인 연습 (컴퓨터 / 한 기기 돌려 하기)
public/js/core.js    덱, 족보 판정, 특수패, 사이드팟 정산 (서버·브라우저 공용)
public/js/game.js    게임 진행 엔진 (서버·브라우저 공용)
public/js/ai.js      컴퓨터 플레이어
public/js/online.js  온라인 화면 처리
public/js/ui.js      오프라인 화면 처리
public/js/cards-ui.js 화투 카드 그리기
public/js/config.js  서버 주소 설정 (보통 비워 둠)
test/test.js         족보 단위 테스트 + 컴퓨터끼리 수만 판 시뮬레이션
test/online-test.js  서버 통합 테스트 (여러 접속자, 재접속, 난입, 나가기, 패 노출 검사)
render.yaml          Render 배포 설정
```

```bash
npm test
```
